# People Counter

Simple JavaScript counter app built during my learning journey on Scrimba.

## About the project

This is my first JavaScript project. The app allows you to:

- increase the counter by clicking the "Increment" button
- save the current value to a list
- reset the counter to 0

## What I learned

While building this project, I practiced:

- basic JavaScript (variables, functions, events)
- DOM manipulation
- working with buttons and user interaction
- updating HTML content using JavaScript

## Tech stack

- HTML
- CSS
- JavaScript
